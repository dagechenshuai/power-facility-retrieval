# 测试与评测

项目将工程回归与检索质量评测分开执行。工程回归检查状态、数据传递和恢复行为；检索评测依赖人工标注问题与知识库快照。

## 工程回归

```powershell
uv run pytest -q --junitxml=examples/tests.xml
```

2026-11-02 归档结果：31 项通过，0 失败、0 跳过。测试使用隔离的 SQLite 数据库，涉及模型和外部业务服务的用例使用替身；查询编排由实际 LangGraph 图执行。

| 范围 | 核心验证 |
| --- | --- |
| 查询接口 | 失败状态、空答案处理、非流式请求不阻塞健康检查 |
| 工具与检索 | 查询参数传递、父块标识一致、并行结果保留、RRF 与重排 |
| 决策循环 | 无结果后补查成功、两轮上限、缺少证据时停止 |
| 流式恢复 | 多连接独立订阅、断开隔离、事件游标、旧失败事件处理 |
| 状态恢复 | 持久进度、LangGraph 检查点、已完成检查点的答案读取 |
| 文档处理 | 图片描述、长文上下文预算 |

完整业务进程强制退出、外部副作用去重、多 worker 抢占和浏览器端到端测试不在这组回归的覆盖范围内。报告中的两条警告来自 FastAPI `on_event` 弃用提示。

## 检索质量评测

```powershell
uv run python -m evaluation.live_rag_eval evaluation/golden.jsonl --k 10 --output evaluation/result.jsonl
uv run python -m evaluation.rag_evaluator evaluation/result.jsonl --k 10
```

`evaluation/dataset.example.jsonl` 定义输入格式。正式数据集应使用当前知识库中的父块 ID，记录问题、相关文档及答案关键词。公开版本不包含企业完整标注集、基线与优化后的逐题输出、图片命中记录或故障恢复实验明细；相关历史指标暂不具备公开独立复现条件。

评测时保留以下信息：

- 数据版本、标注方法及训练、调参、测试集的划分。
- 模型版本、索引配置、检索参数和每个问题的实际返回结果。
- 基线与优化方案的相同测试条件，以及失败样例分析。
- 图片命中的判断规则；恢复实验的故障位置、成功定义及重复执行节点数。

`live_rag_eval` 默认 k=5，评估 Recall@10 时显式指定 `--k 10`。当前脚本读取重排及动态截断后的最终结果，报告应按这一口径解释，不能与重排前的召回指标直接比较。关键词覆盖率只检查目标词出现情况，事实正确性和引用支持关系需要另行核验。
