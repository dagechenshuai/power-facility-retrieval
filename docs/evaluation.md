# 评测与证据边界

## 本次验证

本次修复由 AI 辅助实现、补充回归测试和整理文档，执行结果保存在 `examples/`。这些新增测试不代表实习期间已完成的实验，也不能用来证明简历中的历史提升指标。

测试使用隔离的 SQLite 数据库。模型、向量检索和业务服务在相关回归中使用替身；完整查询图实际由 LangGraph 执行。验证覆盖：失败返回、空答案、非阻塞查询、并行结果保留、工具参数传递、补查成功、补查上限、无证据保护、SSE 多订阅、断开隔离、游标重放、失败后重放及检查点答案恢复。

可运行：

```powershell
uv run pytest -q --junitxml=examples/tests.xml
uv run python -m evaluation.demo
```

`examples/demo-output.json` 为合成资料上的实际 BM25 返回，既不是模型回答，也不是人工标注评测集。测试通过数量以 `examples/tests.xml` 为准。

## 历史指标需要的证据

公开仓库当前没有完整的企业标注集、基线逐题输出、优化后逐题输出或恢复实验明细。因此仅凭此仓库不能独立复核简历中的 Recall@10、MRR、图片命中率、恢复成功率和平均重复节点数。

后续补充真实记录时，至少说明：

- 数据来源与脱敏范围，问题数量、正例标注方法和父块 ID 对应关系。
- 基线和优化方案的模型、索引、参数、同一测试集及各题返回结果。
- 是否在该测试集上调参；训练、调参和最终评测如何分开。
- 图片问题的正确命中判定与失败样例。
- 恢复实验的故障注入位置、成功定义、每次结果和重复节点计数。

没有原始记录的指标应标为未复核，不能事后生成一批数据声称是历史实验。涉及企业保密资料时只公开有授权的脱敏部分，并说明无法公开的范围。

## 当前效果评测限制

`live_rag_eval` 默认 k=5；复核 Recall@10 时显式传 `--k 10`。评测中的关键词覆盖率只衡量词语出现，不等于事实正确率。当前重排会动态截断返回列表，评测记录应明确测量的是最终返回结果，不能与重排前召回指标混用。

需要在真实模型上补测：检索后决策可靠性、规则冲突、文档注入、无资料拒答、引用与答案一致性，以及不同供应商结构化输出兼容性。本次未运行这些真实模型质量评测，也未复核历史性能数字。
